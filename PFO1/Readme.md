# PRIMERA PRÁCTICA FORMATIVA OBLIGATORIA

## Descripción del Proyecto

Este proyecto es una práctica formativa obligatoria (PFO) para la materia FrontEnd perteneciente a la Tecnicatura Superior en Programción del IFTS n°29, en la cual se desarrolla una página web utilizando los lenguajes HTML5 y CSS, para darle estructura y diseño, a nuestra presentación de nuestro portfolio personal de lo desarrollado hasta la fecha y los distintos lenguajes de programación utilizados.

Además se incluye un listado de peliículas favoritas para aplicar el uso del incrustado de elementos multimedia.
Todo esto se debe verificar en un check list que se incluye en el final de este documento.

En este proyecto demostraremos la habilidad para darle formato y diseño a nuestro proyecto y el uso y aplicación de diferentes lenguajes de programación.
